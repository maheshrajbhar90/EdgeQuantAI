# EdgeQuantAI

[![CI](https://github.com/maheshrajbhar90/EdgeQuantAI/actions/workflows/ci.yml/badge.svg)](https://github.com/maheshrajbhar90/EdgeQuantAI/actions/workflows/ci.yml)
[![Python](https://img.shields.io/badge/python-3.10%20%7C%203.11%20%7C%203.12-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](EdgeQuantAI-main/LICENSE)
[![Code style: Ruff](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/astral-sh/ruff/main/assets/badge/v2.json)](https://github.com/astral-sh/ruff)

A typed, tested Python library that turns stock tickers into technical
indicators, candlestick patterns, signals and support/resistance levels, then
packages the result as an LLM-ready analysis prompt. It also includes a
Streamlit chat app for NSE equities.

**The project lives in [`EdgeQuantAI-main/`](EdgeQuantAI-main/).** Start with its
[README](EdgeQuantAI-main/README.md).
